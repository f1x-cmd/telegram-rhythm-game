# Oswald

Шрифт игровых надписей: узкий и тяжёлый, поэтому длинные фразы вроде
«СОВЕЩАНИЕ ОТМЕНЕНО!» помещаются в одну строку на узком телефоне.

Лежит в репозитории, а не подключается с чужого сервера: Mini App должен
запускаться быстро и не зависеть от доступности стороннего домена, а первые
надписи появляются в первые секунды партии.

- Источник: Google Fonts, Oswald v57, начертание 600
- Лицензия: SIL Open Font License 1.1 — https://openfontlicense.org
- Подмножества: `cyrillic`, `latin`, `latin-ext`

Деванагари, арабского и китайского в Oswald нет: для `hi`, `ar` и `zh`
надписи рисуются системным шрифтом — это штатное поведение `@font-face`
с `unicode-range`.
