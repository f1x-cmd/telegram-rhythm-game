## Что работает

- **RELAX.** Собиратель под пальцем, ноты `orb` / `bloom` / `breath` / `chain`,
  полоса CALM растёт от музыки сама, на 100% — BLISS ×2 на 18 с. Проиграть нельзя,
  наказаний нет вообще.
- **DRIVE (Office Rage).** Три сложности. Предметы падают по параболе, режутся
  свайпом в любом месте экрана. Бомбы ведут себя по-разному: Easy — чистят экран,
  Medium — поднимают пыль, Hard — снимают 15% HP. На Medium и Hard у предмета
  жёлтая стрелка: резать нужно вдоль неё. Полоса ЯРОСТЬ → FEVER ×1.45 на 14 с.
  Проиграть можно только на Hard.
- **Свои треки.** Загрузка MP3/WAV/OGG до 20 МБ, авторазметка по онсетам.
  Одна и та же песня всегда даёт одну и ту же карту (`D-12`).
- **Прогресс.** Личные рекорды по «режим|трек|сложность», сумма очков за всё время,
  стрик, лиги и титулы, цель дня (выбирается по дате, одна для всех, сброс в полночь).
- **Соцчасть.** Приглашения, вызовы, кланы через `startapp`-ссылки; карточка
  результата 9:16 для Stories.
- **14 языков** с автоопределением из Telegram, включая арабский с RTL.
- **Сервер.** `/api/score`, `/api/leaderboard`, `/api/stats` на Vercel Functions +
  Upstash Redis. Личность — только из подписи `initData`; сумма очков копится
  на сервере через `ZINCRBY`.
- **Панель оператора** `admin.html`: баннер, техработы, множитель ивента, каталог,
  баланс, живая таблица игроков, локальная телеметрия.

## Что не работает / отключено

- **Донат не подключён.** Пакеты Stars рисуются, но `DONATE.invoices` / `url` / `bot`
  пустые — нажатие никуда не ведёт. См. `T-04`.
- **Классические дорожки** (TAP / HOLD / SWIPE / AVOID / MASH) существуют в коде,
  но выключены: все сложности DRIVE идут через `fruitNinja: true`. Это осознанно (`D-02`),
  не баг.
- **LiveOps без сервера.** Панель правит настройки **только на том устройстве**,
  где открыта. Перенос — выгрузкой JSON вручную.
- **KPI в панели — локальные.** «Обзор» показывает телеметрию этого устройства;
  глобальные цифры — только `/api/stats` и только для id из `ADMIN_IDS`.

## Известные проблемы

- **Нет автоматических проверок.** Любая правка проверяется руками; регрессия
  ловится только глазами. Это главный риск при изменении баланса и ввода.
- **Ощущение от игры не доведено** — основная работа сейчас (`T-01`). Конкретный
  список претензий пока не собран.
- **`.cursorrules` местами противоречит коду** (дорожки, NPS, урон за MISS,
  окно свайпа). Расхождения зафиксированы в `SPECIFICATION.md` пометкой
  «расхождение» и в `DECISIONS.md` (`D-02`…`D-06`). Верить коду, не брифу.
- **Вне Telegram** часть функций молча отключается (хаптика, CloudStorage,
  рекорды сети, вход в админку). Это ожидаемо, но при отладке в браузере
  легко принять за поломку.
