## Стек

- **Клиент:** ES6-модули без сборщика, Canvas 2D, Web Audio API, Telegram WebApp SDK.
  Ни `package.json`, ни `node_modules`, ни бандлера в репозитории нет — и это намеренно (`D-01`).
- **Сервер:** Vercel Functions (Node, папка `api/`), Upstash Redis по REST.
- **Аналитика:** Vercel Web Analytics, обезличенные события (`js/analytics.js`).
- **Шрифт:** Oswald, три `.woff2` локально в `assets/fonts/` — не с CDN (`D-14`).
- **Локальный запуск:** `.claude/launch.json`, `npx http-server . -p 8412 -c-1`.
  Открывать через `http://`, не через `file://` — модули иначе не загрузятся.

## Модули

Полная таблица файлов — `SPECIFICATION.md` §8.8. Крупными мазками:

- **Ядро:** `main.js` (цикл и связка), `config.js` (все константы и баланс),
  `audio-engine.js` (звук и часы), `analysis.js` (онсеты, BPM, генерация карт),
  `input.js` (указатели с метками времени), `pools.js` + `fx.js` (пулы и эффекты).
- **Режимы:** `relax.js`, `drive.js` (+ `fruit.js` — падение и коллизии,
  `office-art.js` — иконки предметов и стрелки).
- **Обвязка:** `ui.js` (экраны, HUD, карточка), `i18n.js` (14 языков, 130 КБ),
  `telegram.js`, `records.js`, `career.js`, `daily.js`, `social.js`,
  `liveops.js`, `telemetry.js`, `backend.js`, `admin.js`.

`js/i18n.js` (≈130 КБ) и `js/drive.js` (≈53 КБ) — самые тяжёлые файлы.
Целиком их не читают: ищут по ключу или по имени функции.

## Данные

Источника правды два, и это осознанно (`D-09`):

1. **На устройстве** — Telegram CloudStorage с резервом в `localStorage`:
   рекорды, карьера, цель дня, язык, `audio_offset`, конфиг LiveOps (`liveops_v1`),
   телеметрия (`telemetry_v1`). Работает всегда, даже без сервера.
2. **На сервере** — Upstash Redis, только для сравнения игроков между собой:
   `lb:total` (сумма за всё время, копится через `ZINCRBY`),
   `lb:c:<режим>:<трек>:<сложность>` (рекорд на карте, `ZADD GT`),
   `u:<id>` (имя и аватар), `dau:<дата>` (живёт 45 дней), `stats` (счётчики).

Клиент **не присылает** свою сумму очков — только результат партии; итог
сервер считает сам. Подробности и границы разумного — `SPECIFICATION.md` §8.7.

## Авторизация

Пароля нет нигде. Личность — исключительно из подписи `initData` Telegram,
сверенной с токеном бота (HMAC, сравнение за постоянное время, проверка срока).
`id` из тела запроса игнорируется.

- **Игрок** — любой, кто открыл мини-апп.
- **Оператор** — Telegram ID из `ADMIN.ids` в `js/config.js` (клиент, вход
  в `admin.html`) и из `ADMIN_IDS` в окружении Vercel (сервер, `/api/stats`).
  Клиентский список публичен по своей природе и дырой не является (`D-10`).

## Внешние сервисы

| Сервис | Роль | Если отвалится |
|---|---|---|
| Telegram WebApp SDK | Личность, хаптика, CloudStorage, шаринг | Игра работает, облако и хаптика молча отключаются |
| Upstash Redis | Таблицы игроков | Клиент помечает бэкенд отсутствующим и живёт на локальных рекордах |
| Vercel Functions | `/api/score`, `/api/leaderboard`, `/api/stats` | То же |
| Vercel Web Analytics | Обезличенные события | Ничего не ломается |

**Переменные окружения** (только в настройках проекта Vercel, никогда в коде):
`TELEGRAM_BOT_TOKEN`, `ADMIN_IDS`, `KV_REST_API_URL`, `KV_REST_API_TOKEN`.
`api/_lib/store.js` умеет находить эти ключи под разными префиксами, которые
подставляет интеграция Upstash.

## Деплой

Push в `main` на `github.com/f1x-cmd/telegram-rhythm-game` → Vercel собирает сам.
Сборочного шага нет: статика отдаётся как есть, `api/*.js` становятся функциями.
Секреты задаются руками в настройках Vercel. Отдельного стенда нет — `main` и есть прод.

## Грабли

- **`file://` не работает.** ES6-модули требуют http. Всегда через `http-server`.
- **Игровое время — только `AudioContext.currentTime`.** `Date.now()`, `setTimeout`,
  `performance.now()` в игровом контуре ломают синхронизацию (`D-03`). Вне контура
  (загрузка, календарь, телеметрия, таймауты UI) — можно.
- **Не аллоцировать в `requestAnimationFrame`.** Ноты, частицы, кольца берутся
  из пулов; `new` и `push` внутри цикла роняют FPS на телефонах.
- **CloudStorage может молчать.** Чтение подстраховано таймаутом 800 мс,
  иначе старт игры зависал бы на iOS.
- **Карточка результата — JPEG, не PNG.** PNG 1080×1920 весит мегабайты и
  не уходит в Telegram (`D-13`).
- **Обрыв сети ≠ «сервера нет».** Флаг «бэкенд отсутствует» защёлкивается только
  по осмысленному отказу, иначе минута без интернета выключала бы таблицу
  до перезапуска игры.
- **Баланс живёт в двух местах.** Заводские значения — `js/config.js`, поверх них
  ложится конфиг LiveOps из `liveops_v1`. Если цифры в игре не сходятся с кодом —
  смотреть, не переопределил ли их LiveOps на этом устройстве.
