SPECIFICATION.md — Техническая спецификация Telegram Rhythm Game1. Общие сведения о проектеНазвание проекта: Telegram Hyper-Casual Rhythm GameЦелевая платформа: Telegram Mini Apps (TMA) & Mobile Web (HTML5 Canvas + Web Audio API)Ориентация экрана: Вертикальная (9:16)Стек технологий: ES6+ JavaScript, Web Audio API, HTML5 Canvas 2D / WebGL, Telegram WebApp SDK2. Архитектурно-технические стандарты2.1. Аудио-движок и синхронизация (Audio Engine & Latency)Единственный источник времени: Системные часы Web Audio API (AudioContext.currentTime).Запрещенные вызовы: setTimeout, setInterval, Date.now(), performance.now() для расчета игровых таймингов и координат нот.Калибровка задержки (Audio Offset): Диапазон от -200 ms до +200 ms.Формула расчета целевого времени ноты:$$t_{\text{render\_target}} = t_{\text{note\_audio\_beat}} + \Delta t_{\text{user\_offset}}$$2.2. Окна точности (Timing Windows)PERFECT+: $\Delta t \le \pm 22\text{ ms}$ | Множитель: 1.2x | HP: +2.0% | Haptic: lightPERFECT: $\Delta t \le \pm 45\text{ ms}$ | Множитель: 1.0x | HP: +1.0% | Haptic: lightGREAT: $\Delta t \le \pm 80\text{ ms}$ | Множитель: 0.7x | HP: +0.5% | Haptic: softGOOD: $\Delta t \le \pm 120\text{ ms}$ | Множитель: 0.4x | HP: 0.0% | Haptic: NoneMISS: $\Delta t > \pm 120\text{ ms}$ | Множитель: 0.0x | HP: -8.0% | Haptic: error2.3. Зонирование экрана (Hand Occlusion Prevention)Spawn Zone (0.00Y — 0.15Y): Верхняя зона появления нот из тумана.Approach Zone (0.15Y — 0.70Y): Зона считывания траектории (запрет на интерфейс, кнопки и текст).Hit Line (0.75Y): Линия судейства.Touch Target Zone (0.70Y — 1.00Y): Нижняя зона приема касаний для исключения перекрытия экрана пальцами.3. Игровая математика, Баланс и Flow State3.1. Плотность нот (NPS) и сложностиEasy: 100–120 BPM | 1.2–2.2 NPS | 1 нота одновременно | Tap, HoldMedium: 120–140 BPM | 2.5–4.0 NPS | До 2 нот (простые аккорды) | Tap, Hold, Swipe (Up)Hard: 140–160 BPM | 4.5–7.5 NPS | До 2 нот + свайпы | Tap, Hold, Swipe (Any), Avoid3.2. Формула подсчета очков$$Score = \sum_{i=1}^{N} \left( S_{\text{base}} \times M_{\text{accuracy}} \times M_{\text{combo}} \right)$$Где:$S_{\text{base}} = 1000$ (базовая ценность ноты).$M_{\text{accuracy}} \in \{1.2, 1.0, 0.7, 0.4, 0.0\}$$M_{\text{combo}} = \min \left( 1.0 + \left\lfloor \frac{\text{Combo}}{10} \right\rfloor \times 0.1, \; 4.0 \right)$3.3. Выживаемость и Novice ShieldМаксимальный запас HP: 100 единиц.Novice Shield: На первых 15 секундах трека или на первых 3 ошибках MISS активируется щит, поглощающий 100% урона по HP.4. Визуальный отклик и Haptic-дизайн5.1. Visual JuiceЧастицы: Пул объектов (Object Pooling) на 15–25 частиц при выбивании PERFECT.Screen Shake: Тряска экрана по затухающей гармонической функции при комбо 10x, 25x, 50x:$$\Delta x = A \cdot e^{-\gamma t} \sin(\omega t)$$5.2. Интеграция Telegram HapticsPERFECT+ / PERFECT: Telegram.WebApp.HapticFeedback.impactOccurred('light')GREAT / GOOD: Telegram.WebApp.HapticFeedback.impactOccurred('soft')HOLD Note: selectionChanged() каждые 100 msMISS: notificationOccurred('error')6. Telegram Интеграция и ВиральностьИнициализация: Чтение имени, фото и ID из Telegram.WebApp.initDataUnsafe.Облачное сохранение: Запись audio_offset пользователя в Telegram.WebApp.CloudStorage.Виральные карточки: Генерация PNG 9:16 на Canvas при завершении уровня для мгновенной публикации в Telegram Stories с глубокой ссылкой (t.me/bot?startapp=challenge_id).Монетизация: Покупка музыкальных паков за Telegram Stars и просмотр Rewarded Video для возобновления игры (Revive) при проигрыше на > 70% прохождения трека.7. Чек-лист Do's & Don'tsDo's (Обязательно)Использовать AudioContext.currentTime как единственный источник времени.Реализовать калибратор задержки в настройках с записью в CloudStorage.Обеспечить показатель Time-to-First-Tap (TTFT) меньше 3.5 секунд.Вызывать нативные функции HapticFeedback в Telegram.Выносить зону ввода в нижние 25% экрана.Использовать Object Pooling для всех элементов Canvas и частиц.Добавить Novice Shield на старте каждого уровня.Генерировать карточки результатов для публикаций в Telegram Stories.Оптимизировать рендеринг для стабильных 60 FPS на бюджетных устройствах.Проверять валидность счета на сервере перед записью в таблицы лидеров.Don'ts (Запрещено)НЕ прерывать игровой процесс рекламой (Interstitial Ads).НЕ использовать Date.now() или setTimeout для игрового цикла.НЕ делать окно PERFECT меньше +-20 ms.НЕ перекрывать Approach Zone элементами интерфейса.НЕ генерировать карты нот простым анализом пиков громкости без учета BPM.НЕ ставить агрессивный пейволл на первых 3 сессиях.НЕ использовать тяжелую постобработку (Post-Processing Bloom), роняющую FPS.НЕ заставлять пользователя проходить регистрацию вручную.НЕ воспроизводить звуки попадания через HTML <audio> теги.НЕ делать монотонные карты нот без связи с ритмическим рисунком.Как использовать этот файл с Cursor:Сохраните этот текст в файле SPECIFICATION.md в корне проекта (рядом с файлом .cursorrules).В Cursor Composer (Ctrl + I или Cmd + I) пишите запросы, ссылаясь на этот документ через @:«Реализуй систему подсчета очков и комбо-множителей в game.js строго по формулам из @SPECIFICATION.md»
