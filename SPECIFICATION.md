## 8. Игровые режимы

Игра построена на двух режимах с общим ядром (аудио, анализ ритма, пулы объектов, FX) и разной механикой ввода.

### 8.1. RELAX — расслабиться

- Цель: слушать музыку, никакого проигрыша.
- Ввод: палец удерживается на экране и ведёт «собиратель» (радиус 10.5% ширины поля); нота засчитывается при пересечении с ним.
- Ноты: свободные координаты X по плавной синусоиде, чтобы соседние ноты собирались одним движением. Типы:
  - `orb` — обычная;
  - `bloom` — крупная, дороже;
  - `still` — «замри»: собиратель должен оставаться на ноте 1.15 с, пока она опускается;
  - `chain` — цепочка из 3–5 нот по одной дуге с шагом `chainStep`; за полный сбор даётся бонус.
- Под `still` и `chain` генератор карты заранее освобождает место, чтобы длинные элементы не наслаивались на обычные ноты.
- Нота становится собираемой только после выхода из Spawn Zone, чтобы нельзя было «припарковать» палец сверху.
- Время подлёта 3.4 с, плотность ~1.5 NPS.
- Полоса HUD показывает FLOW: заполняется за сбор нот, при 100% включается состояние потока на 12 с (двойные очки, смена палитры).
- Сбор рядом с линией 0.75Y даёт бонус SWEET (×1.5). Пропуск ноты только сбрасывает комбо и часть FLOW.
- Звук: мягкий колокольчик по пентатонике через реверб (ConvolverNode с программно сгенерированным импульсом).

### 8.2. DRIVE — сбросить агрессию

- Четыре дорожки, окна точности и HP по разделам 2.3 и 3.3.
- Типы нот: TAP, HOLD (тики удержания каждые 50 мс по часам AudioContext), SWIPE (смещение ≥ 30 px), AVOID (касание отнимает 15% HP, пропуск даёт бонус), MASH (серия быстрых тапов по дорожке за отведённое окно; частичный сбор даёт частичный зачёт).
- «Разгон» — серия из 25 нот без промаха; считается как аналог потока для ежедневной цели.
- Окна точности масштабируются по сложности (`windowScale`): Easy ×1.6, Medium ×1.25, Hard ×1.0 — минимум PERFECT+ 22 мс сохраняется.
- Отклик на удар: синтезированный панч (кик + шумовой транзиент), кольца, 15–25 частиц, вспышка дорожки, тряска экрана на комбо 10/25/50.
- Фон синхронизирован с музыкой: сетка долей по BPM и пульсация по низким частотам через AnalyserNode.

### 8.3. Прогресс игрока

- **Рекорды** (`js/records.js`): личный максимум по ключу `режим|трек|сложность` (в RELAX сложность всегда `zen`). Хранение в Telegram CloudStorage с резервом в `localStorage`. Рекорд виден в списке треков и на экране результата («Первый рекорд» / «Новый рекорд · было N»).
- **Цель дня** (`js/daily.js`): задание выбирается детерминированно по дате (хэш строки `YYYY-MM-DD`), поэтому одинаково в течение дня и сбрасывается в полночь. Метрики: собранные ноты, очки, лучшее комбо, PERFECT, входы в поток/разгоны. Прогресс копится между партиями в обоих режимах, отображается в меню и на экране результата.

### 8.4. Локализация

- Язык по умолчанию берётся из настроек Telegram (`initDataUnsafe.user.language_code`), при запуске вне Telegram — из `navigator.languages`. Неизвестный код сводится к базовому (`pt-BR` → `pt`), иначе используется английский.
- Ручной выбор в меню всегда важнее автоопределения и хранится в CloudStorage с резервом в `localStorage`. Локальная копия читается синхронно при старте, чтобы интерфейс не мигал автоопределённым языком, пока отвечает облако. Вариант «Авто» возвращает поведение по настройкам Telegram.
- Поддерживаются 14 языков: английский, русский, украинский, испанский, португальский, немецкий, французский, итальянский, польский, турецкий, индонезийский, хинди, арабский, китайский (упрощённый).
- Арабский переключает документ в `dir="rtl"`; зеркалятся меню, HUD, кнопка выхода и подписи на карточке результата. Числа форматируются через `Intl.NumberFormat`, для арабского принудительно латинскими цифрами — счёт рисуется на canvas.
- Судейские надписи (`PERFECT+`, `GREAT`, `MISS`, `SMASH!`, `FLOW`) не переводятся: это терминология жанра, одинаковая во всех локализациях.
